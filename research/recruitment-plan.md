# Recruitment Plan for Protocol v2

Companion to `research/protocol-v2.md` (frozen). This file covers
logistics only and may be revised; it cannot alter hypotheses, signals,
sample size, or analysis.

## Target

200 pairs × 9 raters = 1,800 labels, plus 2 attention-check pairs per
rater session.

## Session design

- 20 pairs + 2 attention checks per session ≈ 25 minutes
  (each pair: listen to 2–4 context fragments + candidates A/B, choose
  A / B / Neither).
- 1,800 labels / 20 per session = 90 sessions.

## Platform and budget (primary: Prolific)

- Pay £4.50 per 25-min session (≈ £10.8/hr, above Prolific's
  £9/hr fair-pay floor).
- 90 sessions × £4.50 = £405 + Prolific service fee (~33%) ≈ **£540
  total** (~$690).
- Screening: age ≥ 18, fluent English, self-reported music production
  or instrument experience ≥ 1 year, audio hardware check (headphone
  screen with an antiphase tone pair).
- Fallback/supplement: Audiotool community volunteers via forum post —
  governed by protocol-v2 Amendment A1 (trigger condition, 20% cap,
  source flagging, prespecified primary/sensitivity analyses); this
  file adds no discretion beyond A1.
